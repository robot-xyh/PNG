# 项目运行帮助文档

本文档说明当前项目的常用运行、验证和调试流程。以下命令均从仓库根目录执行：

```bash
cd /path/to/PNG-betaflight-upward-camera
```

## 1. 环境准备

基础测试通常只需要 Python 3、NumPy 和 Matplotlib。可选依赖按需安装：

```bash
python3 -m pip install numpy matplotlib
```

AirSim 路径需要 AirSim Python 包；YOLO 路径需要：

```bash
python3 -m pip install torch ultralytics lap opencv-contrib-python
```

Betaflight MSP 路径需要：

```bash
python3 -m pip install pyserial
```

建议使用虚拟环境，不要提交 `.venv/`、`logs/`、`datasets/` 或大体积媒体文件。

## 2. 基础验证

每次修改先跑单元测试：

```bash
python3 -m unittest discover -s tests -v
```

运行合成示例：

```bash
python3 examples/run_synthetic.py
```

这一步验证 bbox -> LOS -> TTC -> `GuidanceEval` 的纯算法链路。

## 3. AirSim Blocks 示例

只记录 AirSim detection 和导引评估：

```bash
python3 examples/run_airsim_blocks.py --duration-s 30
```

启用 AirSim 内部 motion command：

```bash
python3 examples/run_airsim_blocks.py --enable-motion --intruder-speed 5 --speed-ratio 2
```

AirSim 运行前应通过 `run_blocks_nvidia.sh` 或 `run_blocks_*.sh` 启动 Blocks，使端口 guard 生效。

## 4. AirSim/PX4 上视相机验证

固定相机 strapdown 路径是当前主要仿真验证入口：

```bash
python3 examples/run_airsim_strapdown_vision_png.py \
  --enable-motion \
  --detector-source yolo_bytetrack \
  --yolo-model /path/to/model.pt \
  --yolo-class-id 0
```

可选检测源：

- `airsim`
- `yolo_bytetrack`
- `yolo_kcf`

可选 PX4 command mode：

- `velocity_simple`
- `velocity_yaw_rate`
- `mavlink_offboard`
- `mavlink_body_rate`
- `mavlink_attitude`

注意：PX4 `mavlink_body_rate` 和 `mavlink_attitude` 是仿真/HIL 验证路径，不等同于 Betaflight RC 输入。

## 5. Betaflight log-only 验证

先复制并填写本机配置：

```bash
cp config/betaflight.example.json config/betaflight.local.json
```

只读 MSP：

```bash
python3 examples/run_betaflight_log_only.py \
  --config config/betaflight.local.json \
  --serial-port /dev/ttyUSB0 \
  --duration-s 60 \
  --detector-source none
```

相机 + YOLO log-only：

```bash
python3 examples/run_betaflight_log_only.py \
  --config config/betaflight.local.json \
  --serial-port /dev/ttyUSB0 \
  --duration-s 60 \
  --detector-source yolo_bytetrack \
  --camera-device 0 \
  --yolo-model /path/to/model.pt \
  --yolo-class-id 0
```

输出文件：

- `logs/betaflight_log_<stamp>.csv`
- `logs/betaflight_log_<stamp>_meta.json`

## 6. Betaflight RC 注入验证

只有完成无桨、AUX gate、failsafe、通道方向和 hover throttle 验证后，才允许运行：

```bash
python3 examples/run_betaflight_log_only.py \
  --config config/betaflight.local.json \
  --serial-port /dev/ttyUSB0 \
  --control-mode msp_raw_rc \
  --allow-control \
  --detector-source csv \
  --detections-csv /path/to/detections.csv
```

`--allow-control` 是硬开关；没有该参数不会发送 RC 控制。建议第一次使用 CSV 回放而不是真实相机，便于确认通道方向和限幅。

## 7. 日志检查重点

Betaflight CSV 重点查看：

- `telemetry_error`, `send_error`
- `safety_state`, `safety_reason`
- `telemetry_age_s`, `attitude_age_s`, `watchdog_age_s`
- `aux_enabled`, `voltage_ok`, `watchdog_ok`
- `rc_in_ch*`, `rc_raw_ch*`, `rc_ch*`
- `rc_clipped_ch*`, `rc_slew_limited_ch*`
- `bbox_area_ratio`, `bbox_clipped`
- `los_valid`, `los_innovation_norm`
- `ttc_valid`, `ttc_s`
- `g_eval_x/y/z`

如果出现持续 RC 饱和、持续裁切、watchdog 反复失效或遥测 age 过大，不能进入飞行测试。

## 8. 常见问题

### 缺少 pyserial

```text
pyserial is required for Betaflight MSP
```

安装：

```bash
python3 -m pip install pyserial
```

### YOLO 模型找不到

YOLO 模式不会静默回退到 AirSim detection。检查 `--yolo-model` 路径和 `--yolo-class-id`。

### AirSim 端口冲突

使用仓库提供的 `run_blocks_*.sh` wrapper，让端口 guard 生成实际 RPC/PX4 端口配置。

### Betaflight 没有进入 ACTIVE

检查：

- `--control-mode msp_raw_rc --allow-control`
- AUX 通道是否在配置范围内。
- `telemetry_fresh`, `attitude_synced`, `watchdog_ok`, `voltage_ok`
- 是否有有效目标和有效 `GuidanceEval`。
