## 程序启动

每个科目在Orange Pi前台重新启动，只替换`TEST_ID`：

```bash
cd /home/orangepi/png_betaflight_python

TEST_ID=THRUST_CURVE_REPEAT_01
STAMP=$(date +%Y%m%d_%H%M%S)
RUN_ID="${TEST_ID}_${STAMP}"
LOG_DIR="logs/flight_20260901"
mkdir -p "$LOG_DIR"

python3 -u examples/run_betaflight_log_only.py \
  --config config/betaflight.rk3588.kinematics_log_only.example.json \
  --duration-s 900 --rate-hz 50 \
  --log-dir "$LOG_DIR" --log-prefix "$RUN_ID" \
  --control-mode log_only \
  --detector-source rknn_bytetrack \
  --isolate-rknn-process \
  --main-cpu-affinity 6,7 \
  --rknn-cpu-affinity 4,5 \
  2>&1 | tee "$LOG_DIR/${RUN_ID}_console.log"
```

起飞前在`http://192.168.1.10:8080/`确认：

```text
state=LOG_ONLY, publish=disabled, armed=0, override_active=0
MSP_SET_RAW_RC attempt/write/success/ack = 0
camera/worker/MSP error = 0
```

任一项不符合时取消本架次，不在飞行中SSH修改配置或重启程序。

## 阶段A：推力曲线重复采样

### 起飞前记录

- [x] 含当前电池、Orange Pi和相机的整机起飞质量`2.412 kg`。
- [x] 动力基本信息：`6S 10000 mAh`、`3115-900KV`电机、共四副10x5.0三叶桨、手制ESC。
- [x] 桨叶实物标记`1050R`，确认标称桨距5.0英寸；`R`为反向旋转版本。
- [ ] 补充电池编号/C数；ESC额定电流未知，暂记为非当前限制项，不等于无电流上限。
- [ ] 无视觉目标，目标机不起飞，RC7人工侧，Blackbox已开始记录。

### 桨距确认记录与复核方法

1. 当前实物标记为`1050R`：`10`表示10英寸直径，`50`表示5.0英寸桨距，`R`表示反向旋转版本；三叶数量由实物确认。
2. 无型号时，断开电池并拆下桨，将桨盘旋转平面调水平。
3. 10寸桨半径`R=5 in`；在轴心外`r=0.75R=3.75 in`处选取同一截面。
4. 测量该截面前/后缘高度差`dh`，以及它们沿旋转切向的水平投影距离`c_t`。
5. 计算局部桨叶角`beta=atan(dh/c_t)`，几何桨距为`P=2*pi*r*tan(beta)=2*pi*r*dh/c_t`。
6. 每副桨的三片桨叶分别测量并取平均；有明显扭转时再在`0.70R`复测，记录两个半径的结果。

如果使用数字角度尺，应用小平板连接同一截面的前后缘以近似弦线，不得直接读取弯曲上表面的角度。

### `THRUST_CURVE_REPEAT_01`

1. 人工起飞，基本水平悬停15 s。
2. 做一次自然、平滑的小幅加油门爬升，约1 s，然后恢复悬停。
3. 稳定10 s后，做第二次稍明显但仍平滑的`0.5--1 s`加油门动作。
4. 不要求飞手命中精确PWM，不以达到`1500 us`为目标，不得超过上次摇杆幅度。
5. 恢复悬停10 s，人工落地、最低油门并DISARM，继续记录10 s。

落地后检查日志完整、全部RC写入为0、无failsafe，以及电机、ESC、桨、机架、电池和温度正常。
全部通过后执行`THRUST_CURVE_REPEAT_02`，重复相同动作，不扩大油门、高度或持续时间。

离线按实际`rc_in_ch4`分箱：`[1260,1300)`、`[1300,1350)`、`[1350,1400)`、
`[1400,1450)`、`[1450,1501] us`。上升与回落分开，排除起飞、触地、明显横向动作和
Roll/Pitch绝对值超过5 deg的样本。输出比力、vario/`v_d`、电流、电压、功率、四电机分布、
响应延迟和两架次差异。分析前不修改PNG参数。

## 阶段B：室外双机LOG_ONLY

更换健康电池并重做地面检查。只要推力架次存在输出、链路、飞行或硬件异常，当天双机科目取消。

1. `F00_SKY_HOVER`：拦截机单机人工悬停60 s，目标机不起飞，采集天空负样本。
2. `F03`：目标机在上方侧偏等待点悬停3段，每段20 s；段间小幅改位，不缩小批准间距。
3. `F04`：拦截机人工定点，目标机沿错开的平行通道低速左右各横穿3次，每次间稳定5 s。
4. `F05`可选：只有F03/F04无安全、身份或跟踪问题时，才沿侧偏非碰撞路线缓慢接近和远离3组。

F03目标指标为连续可见段confirmed比例不低于95%、段内ID switch为0、结果年龄P95小于100 ms。
F04检查图像横向中心和LOS符号反转、跟踪连续性和出框立即失效。未达标时只记录差距，不现场改阈值继续飞。

## 立即终止与归档

页面离开`LOG_ONLY`、任一RC写入非0、RC7/override生效、程序/相机/MSP停止更新、遥控或动力异常、
两机距离不足、身份误切、人员进场或任一飞手/观察员要求终止时，目标机先退出工作区，两机人工落地。

每架DISARM后继续记录10 s，再按一次`Ctrl+C`。保存CSV、meta、events、audit、console、SHA256SUMS、原始`.BFL`、
目标机日志、地面视频、口令时间和实际最小间距。任一科目通过都不改变`release_passed=false`。
