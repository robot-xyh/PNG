# Betaflight比例导引硬件约束MC100评估（2026-09-02）

## 1. 结论

基于真实相机内参、最终室内视觉链路时延和漏检数据的3000条Monte Carlo评估中，初始可见目标的
总体命中率为`96.92%`和`97.31%`，全程保持目标在相机视场内的命中率为`89.38%`和`86.54%`。
两个指标在两个时延场景中均高于初期`80%`目标，其95% Wilson区间下界也分别不低于`95.84%`
和`84.58%`。因此：

```text
initial_performance_target_passed = true
release_passed                    = false
actual_flight_hit_rate_measured   = false
```

这里的“通过”只表示该硬件约束离线模型达到初期聚合性能目标，不是实机命中率证明，也不批准
RC7/MSP OVERRIDE主动控制、带桨闭环或碰撞航线。完整放飞门槛仍因视场连续性、陈旧失效和最差
脱靶距离失败。

## 2. 实测输入与模型修正

本轮不再使用旧AirSim `120 deg`视场和目标真值速度。输入改为：

- 真实`640x512`相机内参，等效半视场约水平`30.9 deg`、垂直`24.9 deg`；
- `VM_FINAL_CHAIN_INDOOR_120S_20260902_214423`软件结果年龄P95 `84.556 ms`；
- 屏幕闪变到相机返回P95 `69.583 ms`，保守物理预算取两者之和`154.139 ms`；
- 视场中央实测漏检突发起始概率`0.00128`，突发长度为2帧；边缘5/8帧丢失由真实矩形FOV门控表示；
- GPS/运动学更新`5 Hz`、延迟`209 ms`、速度噪声`0.25 m/s`；
- 候选自身速度明确固定为`Vm=10 m/s`，不读取目标真值速度。

候选控制参数为`N=3`、总加速度上限`7 m/s2`、Roll/Pitch倾角上限`35 deg`、角速度上限
`60 deg/s`、视场居中增益`16 s^-2`、视场居中加速度上限`7 m/s2`、LOS预测上限`0.15 s`，
获取门槛为1个新帧。附加LOS/推力锥约束在参数扫描中降低结果，正式配置保持关闭。

## 3. MC100结果

每个场景包含15个几何工况、每工况100个固定随机种子，共1500条；其中13个工况、1300条在
初始时刻位于实测相机视场内。`U03`和`U14`初始即超出垂直/矩形视场，不进入初始可见率分母。
命中定义为最小距离不大于`1.0 m`。

|场景|初始可见命中|95% Wilson区间|FOV可行命中|95% Wilson区间|陈旧失败|最差距离|
|---|---:|---:|---:|---:|---:|---:|
|软件结果年龄P95，84.556 ms|1260/1300，96.92%|95.84%--97.73%|1162/1300，89.38%|87.59%--90.94%|3.08%|4.23 m|
|保守物理P95预算，154.139 ms|1265/1300，97.31%|96.28%--98.06%|1125/1300，86.54%|84.58%--88.29%|2.69%|5.18 m|

聚合80%初期门槛同时检查“总体命中”和“FOV可行命中”。两个场景中较差值分别为`96.92%`和
`86.54%`，所以阶段判据通过。该结果按13个初始可见工况等权聚合，不代表每个工况都达到80%。

## 4. 未通过项

完整门槛要求FOV可行命中率至少90%、陈旧失败率不高于1%、最差最小距离不大于1 m。两场景均有
失败项，最明显的是`U06`（横向正偏置8 m）：总体命中只有`60%/65%`，FOV可行命中只有
`35%/33%`，陈旧失败`40%/35%`。这说明聚合结果达到80%并不能消除特定入射方向的视场风险。

模型仍采用点质量平动和一阶角速度响应；视觉、风、GPS噪声来自有限实测或保守假设。真实天空
背景、动力振动、执行器饱和、目标机策略和飞手进入条件尚未形成实机命中统计。因此不能把
`96.92%--97.31%`写成预计实机必然命中率。

## 5. 工程判定与下一步

当前候选足以结束“是否有希望达到初期80%”的离线筛选，进入生产代码集成阶段。下一步应先把
`VelocityEstablishingPngController`接入生产runner的`LOG_ONLY`诊断路径，记录状态机、速度参考、
三项加速度、限幅和ABORT原因；此时仍保持`MSP_SET_RAW_RC=0`。完成真实数据回放和LOG_ONLY核对后，
才制定一次短时无桨输出测试。完整`release_passed=false`期间不做带桨自主拦截。
