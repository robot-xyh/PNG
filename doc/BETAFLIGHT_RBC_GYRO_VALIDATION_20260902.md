# Betaflight 相机外参与陀螺轴验证报告（2026-09-02）

## 结论

在`orangepi5max`、`BTFL 25.12.2 / MSP API 1.47`上完成两轮各120秒的拆桨、DISARM、
RC7人工侧、固定目标`LOG_ONLY`采集，并完成一轮90秒20 Hz RAW_IMU偏航复测。三轮审计均通过，所有
`MSP_SET_RAW_RC attempt/write/success/ACK`均为0。本测试只关闭安装外参与
Roll/Pitch/Yaw陀螺坐标缺口，不批准主动控制或装桨自主飞行。

本机相机应使用：

```text
R_BC = [[0, 1,  0],
        [1, 0,  0],
        [0, 0, -1]]
```

OpenCV相机`x右/y下/z光轴`由此映射到FRD机体`y右/x前/z上`，中心光轴为机体`-Z`；矩阵正交、
`det=+1`、光轴误差为0。固定世界目标在抬头、低头、右滚、左滚后的惯性LOS残差分别为
`0.874/2.294/3.419/2.986 deg`，均小于5 deg；旧`pitch_up_deg=90`在相同窗口最大残差
`24.515 deg`。

## Pitch 复测

Betaflight的原始`MSP_ATTITUDE.pitch_deg`抬头为负，而FRD抬头为正，因此用于坐标和姿态包络的
俯仰角是`pitch_frd=-pitch_deg`。`MSP_RAW_IMU / 16`的比例不变，但Y轴转FRD必须取反：

```text
scale = 0.0625 deg/s/LSB
axis_order = [x, y, z]
axis_sign  = [+1, -1, +1]
```

正式动作轮中，未修正的gyro Y与`d(pitch_frd)/dt`相关系数为`-0.964`，取反后为`+0.964`。
独立pitch复测覆盖`17.9 deg`，468个动态样本中相关系数由`-0.969`变为`+0.969`，拟合增益
`0.946`。两轮一致，排除了单次动作标签或偶然噪声。Roll保持`+X`，正式轮相关系数为`+0.959`。

## Yaw 复测

首次5 Hz RAW_IMU试验覆盖`75 deg`，但MSP姿态只有1度量化且采样稀疏，逐样本相关系数
`-0.161`，只能用于发现问题，不能关闭符号缺口。随后临时把ATTITUDE和RAW_IMU都提高到
20 Hz，关闭GPS/高度轮询并把RC轮询降至2 Hz，重新采集90秒。有效轮覆盖`69 deg`，Z轴角速度
范围为`-28.625..27.438 deg/s`。

按`|gyro_z|>5 deg/s`分段并合并短间隔后得到9个有效转动事件。9/9事件的陀螺积分与航向变化
符号一致，事件相关系数为`0.994`，航向变化/陀螺积分拟合增益为`0.876`。因此当前固件和安装
方向下Yaw确认保持`+Z`。逐样本最佳相关系数只有`0.419`，最佳边界滞后落在扫描上限0.4秒；
这是MSP_ATTITUDE量化、异步采样和人工动作边界共同造成的，不用于估计控制响应时延。试验后
轮询已恢复为RAW_IMU/GPS/高度/RC各5 Hz，恢复配置SHA256为
`9e5dbb9de21ca59434c1f53a020a76b7f27d1089721d17ec16c96d2ef11d16c9`。

## 感知与时序

首轮3159个新感知结果中3124个有有效框、3157个confirmed，只有`track_id=1`；结果年龄
P50/P95/max为`56.884/84.514/112.760 ms`。左滚期间因框宽高比门限出现最长`1.288 s`空缺。
pitch复测3116个新结果中3112个有效框、3114个confirmed，最长框空缺`0.120 s`，结果年龄
P50/P95/max为`56.840/84.972/122.206 ms`。

这些结果验证当前静态目标包线内的轴向和跟踪连续性，不等于曝光同步验证。相机时间仍是
`capture_return_monotonic`，硬件曝光时刻未知；控制响应总时延和真实飞行振动仍需单独验证。
机器可读指标及原始文件SHA256见
`doc/evidence/BETAFLIGHT_RBC_GYRO_VALIDATION_20260902.json`。
