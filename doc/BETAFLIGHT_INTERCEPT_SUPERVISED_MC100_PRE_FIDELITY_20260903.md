# Betaflight 监督飞行配置 MC100 预保真基线（2026-09-03）

## 1. 结论

本轮按 `betaflight.rk3588.velocity_png.flight_supervised.json` 的候选参数运行
`4500` 条 Monte Carlo 闭环仿真：3 个时延场景、15 个几何工况、每工况 100 个固定随机
种子。当前配置的初始可见总体命中率为 `97.46%--98.00%`，全程保持目标在相机视场内的命中率
为 `88.31%--91.92%`。

```text
initial_performance_target_passed = true
release_passed                    = false
actual_flight_hit_rate_measured   = false
```

三个场景的总体命中率和 FOV 命中率都高于当前初期 `80%` 聚合目标。但完整门槛要求每个场景
FOV 命中率至少 `90%`、陈旧失效不高于 `1%`、最差最小距离不大于 `1 m`；本轮没有同时满足，
因此结果不能作为自主拦截或碰撞航线放行依据。

## 4. 失败工况

`U06` 是三个场景共同的最差工况：初始水平距离 `10 m`、右侧偏置 `8 m`、高度差 `30 m`、
目标速度 `5 m/s`。其结果为：

|场景|命中率|FOV 可行命中率|检测陈旧终态|
|---|---:|---:|---:|
|84.556 ms|74%|43%|14%|
|127.7 ms|68%|44%|15%|
|154.139 ms|71%|38%|18%|

除 `U06` 外，所有初始可见工况的总体命中率均为 `99%--100%`。但 `U05`、`U10`、`U12`
和 `U15` 在较大时延下也出现明显 FOV 连续性下降。这说明当前候选的主要离线风险仍是固定上视
相机的边缘保持和目标过期，而不是聚合命中率或推力上限。

## 5. 模型边界

本文件是加入交接与油门动态模型之前的预保真基线，不是最终 MC100 结论，也不是真实飞行命中率。
模型使用直线匀速目标，只加入配置的
LOS 噪声、漏检突发、速度噪声和一阶相关风。下列当前运行时行为尚未进入模型：

- `0.8 s`角速度入场平滑；
- `0.8 s`油门交接和 `600 us/s`油门变化率限制；
- Betaflight PID、电机混控、桨动力学、电池压降和机架气动；
- 真实 YOLO 误检、ByteTrack ID 切换及目标机主动机动。

因此 `97.46%--98.00%`只能表述为“当前简化模型中的初始可见命中率”，不能写成预计实机命中率。
`2.37 g`也来自约 `0.4 s`实测平台，不代表可持续推力。
